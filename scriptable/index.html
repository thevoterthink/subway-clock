Leslie to Ian’s Heart: Scriptable widget

Muni 5 / 5R countdown for the Home Screen and Lock Screen.

  1. Install Scriptable from the App Store.
  2. Open Scriptable, tap +, paste, and name it Ian’s Heart.
  3. Tap ▶︎ to run it once. Enter your 511 key (saved in the Keychain), then preview the sizes.
  4. Add a Scriptable widget to the Home Screen or Lock Screen. Long-press it → Edit Widget → Script: Ian’s Heart.
